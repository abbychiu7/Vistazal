# Vistazal

**Vistazal** is a modern, responsive web application designed to showcase stunning landscapes and immersive visual experiences. Whether it's a travel portfolio, a photography gallery, or a destination guide, Vistazal focuses on clean design and seamless user interaction.

## Live Demo
Check out the live project here: [https://abbychiu7.github.io/Vistazal/](https://abbychiu7.github.io/Vistazal/)

## Features
- **Responsive Design:** Fully optimized for desktop, tablet, and mobile devices.
- **High-Quality Visuals:** Optimized image loading for a premium "vista" experience.
- **Modern UI/UX:** Clean typography and intuitive navigation.
- **Interactive Elements:** Smooth transitions and hover effects.

## Technologies Used
- **HTML5:** Semantic structure for better SEO and accessibility.
- **CSS3:** Custom styling with Flexbox/Grid and CSS animations.
- **JavaScript (ES6+):** Dynamic functionality and interactivity.
